## 业务背景

根据新的业务规则：
1. 每个practitioner用户必须有唯一的practitioner_account
2. 医师独立管理自己的账户，不再依托诊所
3. clinics和clinic_accounts表将被废弃

## 影响分析

### 受影响的模块
1. **Order模块** - 订单表包含clinicId字段和外键
2. **Prescription模块** - 处方包含clinicId
3. **权限系统** - 基于clinic的权限检查
4. **WebSocket网关** - clinic级别的广播功能
5. **测试用例** - 大量mock数据包含clinicId
