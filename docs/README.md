# 文档目录结构说明

本目录包含新西兰中医药电子处方平台的所有技术文档，按功能分类组织。

## 📁 目录结构

### `/api/` - API文档
- `API文档.md` - 完整的API接口文档
- `frontend-api-changes.md` - 前端API变更指南

### `/architecture/` - 架构设计
- `improved_micro_sop.md` - 微服务架构SOP v1.3
- `SOPv2.0_DDD_Architecture_MVP1.0.md` - DDD架构设计文档

### `/project-management/` - 项目管理
- `progress.md` - 当前项目进度
- `PROGRESS_TRACKER.md` - 详细进度跟踪记录

### `/team-reports/` - 团队报告
- `core-team-technical-report.md` - 核心团队技术报告
- 各种团队通知和里程碑报告

### `/technical-analysis/` - 技术分析
- `clinic-removal-completion-summary.md` - Clinic依赖移除完成总结
- 各种技术评估和分析报告

### `/guides/` - 开发指南
- `technical-guidance.md` - 技术开发指南
- 角色映射和统一相关指南

## 📋 文档维护规则

1. **新文档分类**：按功能将新文档放入相应目录
2. **命名规范**：使用清晰、描述性的文件名
3. **版本控制**：重要变更需要更新版本号
4. **归档规则**：完成的任务文档移入 `../archive/`

## 🔍 快速查找

- **API接口问题** → `/api/`
- **架构设计问题** → `/architecture/`
- **项目进度查询** → `/project-management/`
- **团队报告查看** → `/team-reports/`
- **技术难题分析** → `/technical-analysis/`
- **开发规范指南** → `/guides/`
