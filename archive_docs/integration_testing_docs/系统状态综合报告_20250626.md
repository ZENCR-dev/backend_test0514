## 🐛 紧急问题：处方API 404错误

### 问题分析
```javascript
// ❌ 前端当前配置（错误）
baseURL: "http://localhost:4000"
url: "/prescriptions"
// 实际请求: http://localhost:4000/prescriptions

// ✅ 正确配置
baseURL: "http://localhost:4000/api/v1"  // 已确认端口
url: "/prescriptions"
// 正确请求: http://localhost:4000/api/v1/prescriptions
```

### 解决方案
1. 修改前端 `apiClient` 配置，添加 `/api/v1` 前缀
2. ✅ 后端已确认运行在4000端口
3. 测试验证所有API端点
