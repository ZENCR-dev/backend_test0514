# 📝 前端便签 - API配置修复

**时间**: 2025-06-26 11:00
**紧急度**: 🔴 高

## 问题
处方API返回404错误：`http://localhost:4000/prescriptions`

## 原因
URL缺少 `/api/v1` 前缀

## 解决方案
修改 apiClient 配置：
```javascript
// ❌ 错误
baseURL: 'http://localhost:4000'

// ✅ 正确
baseURL: 'http://localhost:4000/api/v1'
```

## 重要提示
- ✅ 后端确认运行在 **4000端口**（不是4001）
- ✅ 所有API都需要 `/api/v1` 前缀
- ✅ WebSocket地址: `ws://localhost:4000/ws/orchestration`

## 测试验证
```javascript
// 快速测试
fetch('http://localhost:4000/api/v1/medicines')
  .then(res => res.json())
  .then(data => console.log('✅ API正常'))
```
