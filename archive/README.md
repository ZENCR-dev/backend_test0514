# 文档归档目录

本目录用于存储已完成的任务文档、历史报告和临时文件，保持主工作区的整洁。

## 📁 目录结构

### `/completed-tasks/` - 已完成任务
存储已经完成的项目任务相关文档：
- 架构重构完成报告
- 测试计划和协调文档
- 里程碑完成总结
- 认证和验证完成文档

### `/historical-reports/` - 历史报告
存储过期的分析报告和修复指南：
- 开发进度梳理报告
- 前端修复指令和指南
- 技术深度检查报告
- Task回档通知

### `/temp-files/` - 临时文件
存储临时脚本、测试文件和工具：
- 数据库迁移脚本
- 测试和验证脚本
- 临时配置文件
- 一次性工具脚本

## 📋 归档规则

1. **完成任务归档**：任务完成后，相关文档移入 `completed-tasks/`
2. **报告过期归档**：被新版本替代的报告移入 `historical-reports/`
3. **临时文件归档**：不再使用的脚本和工具移入 `temp-files/`
4. **保留期限**：归档文件保留6个月，之后可考虑删除

## 🔍 查找归档文档

- **需要了解历史任务** → `/completed-tasks/`
- **查看历史分析报告** → `/historical-reports/`
- **寻找临时工具脚本** → `/temp-files/`

## ⚠️ 注意事项

- 归档文档仅供参考，可能包含过期信息
- 临时文件可能依赖特定环境，使用前请检查
- 如需恢复归档文档到主目录，请先确认其当前相关性
